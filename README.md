¡Hola! en este documento te comparto cómo construí este proyecto desde mi computadora hasta dejarlo publicado en vivo en internet usando GitHub y Vercel.
 Paso 1: Organización en Visual Studio Code
 
Abrí mi carpeta del proyecto en Visual Studio Code y organicé todo en archivos separados para mantener el orden:
•	index.html: Toda la estructura semántica, el catálogo, los modales y mi footer con estilo vintage.
•	styles.css: La paleta de colores pastel de los años 60 (crema, verde menta, rosa coral y amarillo mantequilla) y la regla de aislamiento .pdf-doc-root para que los PDFs salgan siempre con fondo blanco y texto oscuro.
•	script.js: La lógica del carrito, el cálculo de alquileres, la pasarela VIP precargada y el motor de html2pdf.js.
.
Probé toda la página localmente usando la extensión Live Server en VS Code para asegurarme de que el diseño, el buscador y la descarga de PDFs funcionaran sin errores.

 Paso 2: Subir el Proyecto a GitHub
Una vez que todo funcionaba perfecto en mi computadora, subí el proyecto a GitHub:
1.	Entré a mi cuenta de GitHub y creé un repositorio nuevo (público y con licencia MIT).
2.	Subí todos mis archivos (index.html, styles.css, script.js, vehiculo.json, pdf_thumbnails.js, README.md y la carpeta assets/) directamente desde la interfaz web de GitHub usando Add file > Upload files y guardé los cambios con un commit.

Paso 3: Desplegar en Vercel
Para que cualquier persona pueda ver mi página en internet:
1.	Entré a Vercel.com e inicié sesión con mi cuenta de GitHub.
2.	Hice clic en "Add New..." > "Project".
3.	Seleccioné mi repositorio de Luxury Motors Elite Corp y presioné Import.
4.	Como es un proyecto de HTML, CSS y JavaScript puro, dejé la configuración tal como viene por defecto y le di clic a Deploy.
5.	En unos segundos, Vercel me dio el enlace público oficial de mi página funcionando en vivo.
